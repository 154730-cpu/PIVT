# Getting Started with IFrameVT

IFrameVT allows you to embed websites within a customizable browser-like interface. To initialize IFrameVT, fill in the following fields:

## 1. Tab Title

The title displayed on the browser tab.

Example:

Agenda – Magister
## 2. Tab Icon URL

The URL of the icon displayed on the browser tab.

You can use:

A local image URL
A hosted image URL
A favicon URL

Example:

file:///home/chronos/user/Downloads/magister.png
## 3. Fallback URL

A website that will be loaded when the embedded content is closed or hidden.

Example:

https://ja.magister.net/magister/#/vandaag
Auto-Redirect

When enabled, IFrameVT automatically redirects the tab to the configured fallback URL when the embedded content is closed. This can be useful for quickly returning to a primary website or workflow.

## 4. IFrame URL

The URL of the website you want to display inside the iframe.

Example:

https://castle.xyz/@krokogames
Important

Some modern websites prevent themselves from being embedded in iframes through browser security policies (such as X-Frame-Options or Content-Security-Policy). In these cases, the website may not load correctly inside IFrameVT.
